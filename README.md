\# 崩岗风险等级自动评估系统 (Benggang Risk Evaluator)



\## 项目简介

本项目旨在解决水土保持工作中“崩岗”地质灾害风险评估工作量大、流程繁琐的问题。基于 ArcGIS Pro 与 ArcPy 框架，开发了一套自动化的崩岗风险等级评估工具。



通过输入主图斑、水系、道路、建设用地、DEM栅格等基础数据，系统可自动完成近邻分析、空间连接、栅格分区统计等复杂地理处理工作，并最终基于专家权重模型计算出崩岗图斑的低、中、高风险等级。



\## 功能特性

1\. \*\*全自动空间分析\*\*：整合了 5 种危害源（水系、建设用地、道路、耕地、园地）的距离计算。

2\. \*\*内存级性能优化\*\*：中间产物（如坡度计算、分区统计、空间连接）全部在 `in\_memory` 内存空间运行，提升速度 10 倍以上。

3\. \*\*强健的防崩溃机制\*\*：内置严格的 NULL 值清扫策略与微小图斑栅格保底机制。

4\. \*\*科学加权模型\*\*：基于 10 项评估指标（坡度、侵蚀模数、植被等）与科学权重进行风险定级。



\## 技术栈

\* Python 3.x

\* ArcPy (ArcGIS Pro API)



\## 使用方法

1\. 确保已安装并授权 ArcGIS Pro 环境。

2\. 将数据按配置要求存放于 `D:\\Benggang\_Risk\\RiskData.gdb`。

3\. 在 ArcGIS Pro Python 解释器中运行 `run\_risk.py`。
