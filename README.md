# 🌍 基于双大模型协同的 GIS 影像全链路自动化处理智能体

## 📂 一、 项目简介
本项目旨在打造一个面向地质灾害（如崩岗）风险评估的 **GIS 自动化处理智能体**。基于大型事业单位复杂的测绘与空间分析业务流，利用大语言模型（LLM）赋能零编程基础的业务人员，将原本高度依赖人工的手动 GIS 数据处理流程升级为“规范命名输入 -> 自动化空间计算 -> 风险评估报告输出”的端到端智能工作流。

---

## ⚠️ 二、 业务痛点与背景
在我们大型事业单位的日常业务中，地理信息系统（ArcGIS Pro）的应用极其高频，但也面临严重的效率瓶颈：
1. **流程繁琐耗时**：以一个县域的“崩岗地质灾害风险评估”为例，包含 10 余项复杂指标（如距水系距离、坡度、植被类型、侵蚀模数等）。传统模式下，业务人员需要手动执行缓冲区分析、多次表格连接（Join）、字段计算器条件赋值等重复性操作，单县域处理周期长达 **1 天**。
2. **技术门槛高**：业务人员普遍缺乏 Python (ArcPy) 编程能力，无法自行编写脚本实现自动化，导致高度依赖“纯手工”操作，不仅效率低下，且极易在繁杂的“按属性选择”中出现人为数据遗漏或错误。

---

## 🛠️ 三、 解决方案与技术实现 (Multi-Agent 架构)
为了打破上述瓶颈，本项目创新性地构建了**“顾问专家 + 编码智能体”的双模型协同开发工作流**：

* **架构设计（AI 顾问 - Gemini）**：深度解析长达几十页的《崩岗专项调查解译阶段操作手册》。将其中的复杂业务逻辑（如模糊匹配、1-5分等级赋分权重）转化为清晰的伪代码和系统架构图。
* **落地执行（AI 智能体 - Claude）**：将梳理好的业务逻辑注入代码生成模型，通过自然语言交互，直接生成可运行在 ArcGIS Pro 中的 ArcPy 自动化脚本。
* **应用形态**：最终业务人员只需确保输入文件命名规范，智能体即可自动完成：**多图层近邻分析 -> 属性表自动连接 -> 空间数据相交 -> 风险指标综合运算打分** 的全流程闭环。

# 利用 ArcPy 实现多图层批量近邻分析与自动化清废，彻底告别人工点选
def batch_near_analysis(main_fc, source_list): 
    for source_name, target_field in source_list:
        arcpy.analysis.Near(in_features=main_fc, near_features=source_name)
        arcpy.management.CalculateField(in_table=main_fc, field=target_field, expression="!NEAR_DIST!", expression_type="PYTHON3")
        arcpy.management.DeleteField(in_table=main_fc, drop_field=["NEAR_DIST", "NEAR_FID"])
